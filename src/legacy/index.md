List of SchildiChat clients no longer actively maintained:
- [SchildiChat Legacy for Android](android), the first generation of SchildiChat Android
- [SchildiChat Desktop](desktop) based on Element Web _(if you want to stick to it for now, it is recommended to use the latest [GitHub pre-release](https://github.com/SchildiChat/schildichat-desktop/releases/tag/v1.11.109-sc.0.test.0), but expect missing features)_
- [SchildiChat Web](https://app.schildi.chat) based on Element Web, _lacking support for authenticated media (so expect missing images like avatars)_. **This will go away soon™.**
