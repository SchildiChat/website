| SchildiChat | Platform | Description |
| --- | --- | --- |
| [Legacy](/legacy/android) | Android | Barely maintained.<br>The original "SchildiChat". A fork of RiotX (known today as "Element Classic"). |
| [Desktop](/legacy/desktop) | Web, Desktop | Archived.<br>The first SchildiChat desktop client, as fork of Element Web. |
| [Alpha ("lite")](/legacy/desktop) | Web, Desktop | Archived.<br>A redo of the previous Element Web fork with only minimal changes, to make it somewhat maintainable again. |
| [Next](/next) | Android | Maintained.<br>2nd generation Android client. A fork of Element X. |
| [Revenge](/revenge) | Desktop, Android | Beta / actively maintained.<br>Originally desktop-only, later also ported to Android. First client to not be an Element fork. |
